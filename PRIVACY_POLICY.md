# Privacy Policy for NeuroScale Pro

Effective date: 2026-04-04

NeuroScale Pro is a clinical support application used to record and review neuropsychiatric assessment information.

## Data We Collect

The app may process the following information entered by users:

- Patient profile data (for example: name, age, gender, contact details)
- Clinical notes and assessment scores
- Voice input transcriptions for data entry support

## How Data Is Used

We use collected data only to:

- Perform in-app assessments and scoring
- Generate summaries and trend analytics
- Support clinical workflow inside the application

## Microphone Permission

The app requests `android.permission.RECORD_AUDIO` only to support optional voice-based data entry.

- Microphone access is used only when the user starts voice input.
- Users can continue using the app without voice input.

## Data Storage and Sharing

- Data is stored locally on the device by default.
- We do not sell personal data.
- We do not share personal data with third parties for advertising.

## Security

We apply reasonable measures to protect data handled by the app. Users and organizations are responsible for secure device access controls and account/device management.

## Children

This app is intended for professional clinical use and is not directed to children.

## Your Choices

You can:

- Stop using voice input at any time
- Revoke microphone permission in Android settings
- Remove app data by uninstalling the app or clearing app storage
